# 访问链路具象示例

本文用一组固定示例值串起 base 登录、业务授权、`TR` 获取和 MCP 调用链路，方便记忆 `code / Tc / T1 / TR / ticketST / token_result_ticket / site_session` 的关系。

本文不新增设计口径；正式口径仍以 `02_引入Agent网关版方案.md`、`03_令牌设计.md` 和接口明细为准。

## 1. 示例背景

```text
业务 Agent：ERP助手
agent_id：agt_erp_assistant
Agent 网关 OAuth client_id：gw_client_001
用户：张建国
用户工号：z01062668
用户 UUID：uuid-user-8899
业务 Agent 页面：https://erp-agent.example.com/agent
Agent 网关：https://agent-gateway.example.com
IDaaS：https://idaas.example.com
IAM：https://iam.example.com
MCP 网关：https://mcp-gateway.example.com
```

## 2. 第一段：进入业务 Agent，建立 site_session

用户打开业务 Agent 页面：

```http
GET https://erp-agent.example.com/agent
```

业务 Agent 检查浏览器 Cookie，发现没有自己的站点会话：

```http
Cookie: 无 site_session_id
```

业务 Agent 把浏览器跳到 Agent 网关：

```http
302 Location: https://agent-gateway.example.com/gw/auth/login
  ?agent_id=agt_erp_assistant
  &return_url=https%3A%2F%2Ferp-agent.example.com%2Fagent
  &state=agent_login_state_789
```

其中：

```text
state = agent_login_state_789
```

这是业务 Agent 自己生成的外部状态值，用于恢复前端上下文、防止串流程。

Agent 网关收到请求后，生成自己的内部 OAuth state：

```text
gw_state = gw_login_state_001
```

Agent 网关保存 base 登录事务：

```json
{
  "gw_login_state_001": {
    "agent_id": "agt_erp_assistant",
    "return_url": "https://erp-agent.example.com/agent",
    "outer_state": "agent_login_state_789",
    "expires_at": "2026-05-18T10:05:00+08:00"
  }
}
```

然后 Agent 网关把浏览器跳到 IDaaS：

```http
302 Location: https://idaas.example.com/oauth2/authorize
  ?response_type=code
  &client_id=gw_client_001
  &agent_id=agt_erp_assistant
  &redirect_uri=https%3A%2F%2Fagent-gateway.example.com%2Fgw%2Fauth%2Fbase%2Fcallback
  &scope=base
  &state=gw_login_state_001
```

IDaaS 判断用户是否已登录。如果没有 IDaaS 登录态，就展示登录页；如果已有 IDaaS 登录 Cookie，就可以快速回调 Agent 网关。

用户登录成功后，IDaaS 回调 Agent 网关：

```http
GET https://agent-gateway.example.com/gw/auth/base/callback
  ?code=code_base_A1B2C3
  &state=gw_login_state_001
```

这里的：

```text
code_base_A1B2C3
```

是 OAuth2 authorization code。它表示用户已经在 IDaaS 完成 base 登录，Agent 网关可以拿这个 `code` 去 IDaaS 后端换 `Tc`。

Agent 网关此时不把 `code` 给业务 Agent，而是生成：

```text
ticketST = ticketST_login_XYZ001
```

并保存绑定关系：

```json
{
  "ticketST_login_XYZ001": {
    "agent_id": "agt_erp_assistant",
    "authorization_code": "code_base_A1B2C3",
    "client_id": "gw_client_001",
    "redirect_uri": "https://agent-gateway.example.com/gw/auth/base/callback",
    "return_url": "https://erp-agent.example.com/agent",
    "used": false,
    "expires_at": "2026-05-18T10:05:00+08:00"
  }
}
```

浏览器回到业务 Agent，只携带一次性票据和业务 Agent 原始 state：

```http
302 Location: https://erp-agent.example.com/agent
  ?ticketST=ticketST_login_XYZ001
  &state=agent_login_state_789
```

业务 Agent 后端用 `ticketST` 向 Agent 网关换取用户信息：

```http
POST https://agent-gateway.example.com/gw/auth/ticket/exchange
Content-Type: application/json
```

```json
{
  "agent_id": "agt_erp_assistant",
  "ticketST": "ticketST_login_XYZ001"
}
```

Agent 网关查到 `ticketST_login_XYZ001` 绑定的 OAuth2 code：

```text
code_base_A1B2C3
```

于是 Agent 网关后端调用 IDaaS token 接口：

```http
POST https://idaas.example.com/oauth2/token
Authorization: Basic base64(gw_client_001:gw_secret_abc)
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
&code=code_base_A1B2C3
&redirect_uri=https%3A%2F%2Fagent-gateway.example.com%2Fgw%2Fauth%2Fbase%2Fcallback
```

IDaaS 返回 base 登录阶段的 `Tc`：

```json
{
  "access_token": "Tc_login_eyJhbGciOiJSUzI1NiJ9.xxx",
  "token_type": "Bearer",
  "expires_in": 3600
}
```

这个 `Tc` 的 payload 示例：

```json
{
  "iss": "idaas",
  "sub": "z01062668",
  "aud": "agent-gateway",
  "user": {
    "user_id": "z01062668",
    "uuid": "uuid-user-8899",
    "username": "张建国"
  },
  "consented_scopes": [
    "base"
  ]
}
```

Agent 网关再用这个 `Tc` 调 IDaaS 用户信息接口，并把用户信息返回业务 Agent：

```json
{
  "user": {
    "userId": "z01062668",
    "uuid": "uuid-user-8899",
    "username": "张建国"
  },
  "expiresIn": 60
}
```

业务 Agent 创建自己的站点登录态：

```text
site_session_id = site_sess_ERP_778899
```

业务 Agent 本地保存：

```json
{
  "site_sess_ERP_778899": {
    "user_id": "z01062668",
    "uuid": "uuid-user-8899",
    "username": "张建国"
  }
}
```

并给浏览器写 Cookie：

```http
Set-Cookie: site_session_id=site_sess_ERP_778899; HttpOnly; Secure
```

到这里，业务 Agent 已经知道当前浏览器对应的用户是谁。

## 3. 第二段：发起业务请求，获取 TR

用户在 ERP 助手输入：

```text
帮我查询合同 C-10086
```

浏览器请求业务 Agent：

```http
POST https://erp-agent.example.com/chat/send
Cookie: site_session_id=site_sess_ERP_778899
```

业务 Agent 通过 `site_session_id` 查到当前用户：

```text
z01062668 / 张建国
```

业务 Agent 判断这次请求需要调用 MCP 工具：

```text
mcp:contract-server/get_contract
```

业务 Agent 检查本地是否已有覆盖该工具的可用 `TR`。如果没有，就调用 Agent 网关申请资源令牌：

```http
POST https://agent-gateway.example.com/gw/token/resource-token
Content-Type: application/json
```

```json
{
  "agent_id": "agt_erp_assistant",
  "required_tools": [
    "mcp:contract-server/get_contract"
  ],
  "return_url": "https://erp-agent.example.com/agent",
  "state": "agent_auth_state_456",
  "subject_hint": {
    "userId": "z01062668"
  }
}
```

Agent 网关问策略中心：这个工具需要哪些权限点。策略中心返回：

```json
{
  "requiredPermissionPointCodes": [
    "erp:contract:r"
  ]
}
```

Agent 网关创建授权事务：

```text
request_id = req_TR_20260518_0001
gw_state = gw_auth_state_002
```

保存内容示例：

```json
{
  "req_TR_20260518_0001": {
    "agent_id": "agt_erp_assistant",
    "required_tools": [
      "mcp:contract-server/get_contract"
    ],
    "requiredPermissionPointCodes": [
      "erp:contract:r"
    ],
    "return_url": "https://erp-agent.example.com/agent",
    "outer_state": "agent_auth_state_456",
    "subject_hint": {
      "userId": "z01062668"
    }
  }
}
```

Agent 网关返回业务 Agent：

```json
{
  "status": "REDIRECT_REQUIRED",
  "request_id": "req_TR_20260518_0001",
  "redirect_url": "https://agent-gateway.example.com/gw/auth/authorize?request_id=req_TR_20260518_0001"
}
```

业务 Agent 让浏览器跳转：

```http
GET https://agent-gateway.example.com/gw/auth/authorize?request_id=req_TR_20260518_0001
```

Agent 网关再跳 IDaaS 授权页：

```http
302 Location: https://idaas.example.com/oauth2/authorize
  ?response_type=code
  &client_id=gw_client_001
  &agent_id=agt_erp_assistant
  &redirect_uri=https%3A%2F%2Fagent-gateway.example.com%2Fgw%2Fauth%2Fconsent%2Fcallback
  &scope=erp%3Acontract%3Ar
  &state=gw_auth_state_002
  &login_hint=z01062668
```

用户确认授权后，IDaaS 回调 Agent 网关：

```http
GET https://agent-gateway.example.com/gw/auth/consent/callback
  ?code=code_consent_D4E5F6
  &state=gw_auth_state_002
```

这个新的：

```text
code_consent_D4E5F6
```

是授权 `erp:contract:r` 后的 OAuth2 authorization code。

Agent 网关用它向 IDaaS 换授权阶段的 `Tc`：

```http
POST https://idaas.example.com/oauth2/token
Authorization: Basic base64(gw_client_001:gw_secret_abc)
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
&code=code_consent_D4E5F6
&redirect_uri=https%3A%2F%2Fagent-gateway.example.com%2Fgw%2Fauth%2Fconsent%2Fcallback
```

IDaaS 返回：

```json
{
  "access_token": "Tc_auth_eyJhbGciOiJSUzI1NiJ9.yyy",
  "expires_in": 3600
}
```

授权阶段 `Tc` 的 payload 示例：

```json
{
  "iss": "idaas",
  "sub": "z01062668",
  "aud": "agent-gateway",
  "user": {
    "user_id": "z01062668",
    "uuid": "uuid-user-8899",
    "username": "张建国"
  },
  "consented_scopes": [
    "erp:contract:r"
  ]
}
```

随后 Agent 网关向 IAM 申请 `T1`，也就是 Agent 令牌：

```http
POST https://iam.example.com/iam/projects/com.huawei.erp.agent/assume_agent_token
Authorization: Bearer iam_admin_or_sdk_token_123
Content-Type: application/json
```

```json
{
  "data": {
    "type": "assume_agent_token",
    "attributes": {
      "delegator_account_name": "Agent_agt_erp_assistant",
      "delegator_appid": "com.huawei.erp.agent"
    }
  }
}
```

IAM 返回：

```json
{
  "access_token": "T1_agent_eyJhbGciOiJSUzUxMiJ9.zzz",
  "token_type": "IAM_AI_SERVICE",
  "expires_in": 86399
}
```

`T1` payload 示例：

```json
{
  "iss": "iam",
  "sub": "Agent_agt_erp_assistant",
  "aud": "agt_erp_assistant",
  "enterprise": "ent_001",
  "account_type": "IAM_AI_SERVICE",
  "project": "com.huawei.erp.agent",
  "agent": {
    "agent_id": "agt_erp_assistant",
    "agent_name": "ERP助手",
    "agent_type": "server"
  }
}
```

接下来 Agent 网关用 `T1 + Tc` 向 IAM 申请 `TR`：

```http
POST https://iam.example.com/iam/auth/resource-token
Authorization: Bearer T1_agent_eyJhbGciOiJSUzUxMiJ9.zzz
Content-Type: application/json
```

```json
{
  "data": {
    "type": "resource_token",
    "attributes": {
      "user_token": "Tc_auth_eyJhbGciOiJSUzI1NiJ9.yyy"
    }
  }
}
```

IAM 返回最终资源令牌 `TR`：

```json
{
  "access_token": "TR_resource_eyJhbGciOiJSUzUxMiJ9.rrr",
  "expires_in": 86399,
  "token_type": "IAM_AI_SERVICE"
}
```

`TR` payload 示例：

```json
{
  "iss": "iam",
  "sub": "com.huawei.erp.agent",
  "aud": "agt_erp_assistant",
  "enterprise": "ent_001",
  "agent": {
    "agent_id": "agt_erp_assistant",
    "agent_name": "ERP助手",
    "agent_type": "server"
  },
  "agency_user": {
    "idp": "idaas",
    "user": "{\"uid\":\"z01062668\",\"uuid\":\"uuid-user-8899\",\"displayNameCn\":\"张建国\",\"tenantId\":\"ent_001\"}",
    "consented_scopes": [
      "erp:contract:r"
    ]
  }
}
```

Agent 网关不把 `TR` 放进浏览器 URL，而是生成：

```text
token_result_ticket = trt_ERP_0001
```

并保存：

```json
{
  "trt_ERP_0001": {
    "request_id": "req_TR_20260518_0001",
    "agent_id": "agt_erp_assistant",
    "tr": "TR_resource_eyJhbGciOiJSUzUxMiJ9.rrr",
    "agency_user": {
      "user_id": "uuid-user-8899",
      "global_user_id": "z01062668"
    },
    "consented_scopes": [
      "erp:contract:r"
    ],
    "used": false,
    "expires_at": "2026-05-18T10:10:00+08:00"
  }
}
```

浏览器回到业务 Agent：

```http
302 Location: https://erp-agent.example.com/agent
  ?token_result_ticket=trt_ERP_0001
  &request_id=req_TR_20260518_0001
  &state=agent_auth_state_456
```

业务 Agent 后端用 `token_result_ticket` 换 `TR`：

```http
POST https://agent-gateway.example.com/gw/token/result/exchange
Content-Type: application/json
```

```json
{
  "agent_id": "agt_erp_assistant",
  "request_id": "req_TR_20260518_0001",
  "token_result_ticket": "trt_ERP_0001"
}
```

Agent 网关返回：

```json
{
  "status": "TOKEN_READY",
  "request_id": "req_TR_20260518_0001",
  "access_token": "TR_resource_eyJhbGciOiJSUzUxMiJ9.rrr",
  "expires_in": 86399,
  "agency_user": {
    "user_id": "uuid-user-8899",
    "global_user_id": "z01062668"
  },
  "consented_scopes": [
    "erp:contract:r"
  ]
}
```

业务 Agent 校验当前 `site_session` 用户和 `TR` 用户一致：

```text
当前 site_session 用户 = z01062668
TR.agency_user.user.uid = z01062668
校验通过
```

业务 Agent 写入本地 `tr_cache`：

```json
{
  "site_sess_ERP_778899 + agt_erp_assistant": {
    "current_tr": "TR_resource_eyJhbGciOiJSUzUxMiJ9.rrr",
    "coveredPermissionPointCodes": [
      "erp:contract:r"
    ],
    "expires_at": "2026-05-19T10:00:00+08:00"
  }
}
```

最后业务 Agent 带 `TR` 调 MCP 网关：

```http
POST https://mcp-gateway.example.com/mcp/call
Authorization: Bearer TR_resource_eyJhbGciOiJSUzUxMiJ9.rrr
Content-Type: application/json
```

```json
{
  "tool": "mcp:contract-server/get_contract",
  "arguments": {
    "contractNo": "C-10086"
  }
}
```

MCP 网关运行时校验：

```text
TR.aud = agt_erp_assistant
当前 Agent = agt_erp_assistant
一致

TR.agency_user.user.uid = z01062668

当前工具 mcp:contract-server/get_contract 需要权限点 erp:contract:r

TR.agency_user.consented_scopes 包含 erp:contract:r
通过

策略中心判断 z01062668 是否允许在 agt_erp_assistant 使用 erp:contract:r
通过
```

通过后，MCP 网关才真正调用 MCP 服务。

## 4. 关键值速记

```text
code_base_A1B2C3
  -> IDaaS 给 Agent 网关的 base 登录 code

ticketST_login_XYZ001
  -> Agent 网关生成，绑定 code_base_A1B2C3
  -> 业务 Agent 用它换用户信息
  -> 换完创建 site_session_id=site_sess_ERP_778899

code_consent_D4E5F6
  -> IDaaS 给 Agent 网关的业务授权 code

Tc_auth_eyJhbGciOiJSUzI1NiJ9.yyy
  -> Agent 网关用 code_consent_D4E5F6 从 IDaaS 换到
  -> 表示用户 z01062668 授权了 erp:contract:r

T1_agent_eyJhbGciOiJSUzUxMiJ9.zzz
  -> Agent 网关从 IAM 获取
  -> 表示 Agent agt_erp_assistant 的身份

TR_resource_eyJhbGciOiJSUzUxMiJ9.rrr
  -> Agent 网关用 Tc_auth + T1_agent 从 IAM 换到
  -> 表示 agt_erp_assistant 可以代表 z01062668 使用 erp:contract:r

trt_ERP_0001
  -> Agent 网关生成，绑定 TR_resource
  -> 业务 Agent 用它换 TR

site_sess_ERP_778899
  -> 业务 Agent 自己创建的网站登录态
  -> 后续用于识别当前浏览器里的用户是谁
```

## 5. 一句话记忆

```text
code 是 IDaaS 给 Agent 网关的兑换凭证。
ticketST 是 Agent 网关给业务 Agent 的登录结果取件票。
Tc 是用户是谁、用户授权了什么。
T1 是 Agent 是谁。
TR 是这个 Agent 可以代表这个用户访问什么。
token_result_ticket 是 Agent 网关给业务 Agent 的 TR 取件票。
site_session 是业务 Agent 自己创建的网站登录态。
```
