## 4. 自动化与复用设计

本人通过框架能力与模块内公共封装减少测试依赖和重复准备工作：

- IDaaS、IAM及管理面客户端通过MockRestServiceServer隔离外部服务，验证实际HTTP构造；`RealIdaasTokenClientTest.expectUserInfo`复用userinfo响应准备。
- 策略中心测试通过MockMvc驱动HTTP入口，经Service和MyBatis访问H2，复用`upsertContractPermissionPoint`、`upsertAgentPermissionPointSnapshot`等准备函数；测试上下文在每个方法后重建以隔离数据。
- Demo的网关client、策略中心client及Mock MCP按接口替换，支持分别验证授权、缓存和运行时裁决。

这些是模块测试能力和类内复用封装，不宣称已经建设跨项目测试平台。根POM聚合三个应用，可由统一Maven命令驱动；当前仓库未发现CI配置，不能据此声称已有持续运行记录。

## 5. 复现方法与结果提取

在仓库根目录执行，不需要访问生产数据库：

```powershell
mvn -q test
```

也可按模块运行，例如：

```powershell
mvn -q -f services/policy-center/pom.xml test
```

执行后读取每个模块`target/surefire-reports/TEST-*.xml`的`tests`、`failures`、`errors`和`skipped`属性，核对与第1节一致。`target`目录是可重建产物，不作为源码暂存；如需上传原始报告，应先检查并脱敏运行时配置。
